## ⚡ 5-Minute Quick Start

### Step 1: Open PowerShell
Press `Win + R`, type `powershell`, press Enter

### Step 2: Navigate to Portfolio
```powershell

```

```powershell

```
⏳ Wait 2-3 minutes while it installs React, animations, styling, etc.

### Step 4: Start Development
```powershell

```

### Step 5: Open in Browser
The terminal will show:

Click the link or paste it in your browser.

## 🎨 Customization Quick Tips

### Change Your Name
1. Open `src/components/Hero.jsx`
2. Find line with "SUBHASANGAR"
3. Replace with your name
4. Save - it updates automatically!

### Change Colors
1. Open `tailwind.config.js`
2. Find `accent: "#39ff14"`
3. Change hex code to your color
4. Save - applies everywhere!

### Update Skills
1. Open `src/components/Skills.jsx`
2. Find the `skills` array
3. Add/remove/edit skills
4. Save - updates instantly!

### Update Contact Info
1. Open `src/components/Contact.jsx`
2. Find `contactInfo` object
3. Update phone, email, location
4. Save!

## ⚠️ Common Issues & Fixes

| Problem | Solution |
|---------|----------|
| `npm: command not found` | Install Node.js from nodejs.org |
| Port 3000 already in use | Edit vite.config.js, change port to 3001 |
| Changes not showing | Press `Ctrl+Shift+R` in browser (hard refresh) |
| Images not showing | Put images in `images/` folder |
| Animations slow | Try different browser or disable extensions |
