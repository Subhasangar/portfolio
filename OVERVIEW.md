## 🎬 Animation Examples

### Navbar
```
On Load:
  └─ Slides down from top (smooth)

On Hover (desktop menu):
  └─ Text color: white → accent green
  └─ Underline animates from left to right
  
On Mobile:
  └─ Menu slides down with staggered items
```

### Hero Section
```
On Load:
  ├─ Title fades and slides in
  ├─ Subtitle follows with delay
  ├─ Buttons fade in
  └─ Rotating circles appear with scale animation

On Hover (buttons):
  └─ Buttons scale up slightly with smooth transition

Continuous:
  ├─ Outer circle rotates 360° (20s loop)
  ├─ Inner circle rotates opposite (-360°, 20s loop)
  └─ Code icon floats up and down
```

### Skills Cards
```
On Load:
  └─ Cards slide up from bottom with stagger (each 0.1s delay)

On Hover:
  ├─ Card moves up 10px (translateY)
  ├─ Icon rotates 360°
  ├─ Border color changes to accent
  ├─ Glow effect appears
  └─ Bottom line animates (scaleX)
```

### Projects Carousel
```
On Load:
  └─ Slides in with smooth transition

Auto-play:
  ├─ Rotates every 6 seconds
  └─ Pauses on hover

On Slide Change:
  └─ Smooth spring animation between slides
```

### Contact Form
```
On Focus:
  ├─ Input field border turns accent color
  └─ Glow box-shadow appears

On Hover (submit button):
  ├─ Button scales slightly
  └─ Glow effect enhances

On Submit:
  └─ Loading spinner appears
  └─ Success message shown
  └─ Form resets after 3s
```
